# 解析原理

## 一、抖音：短链 → 无水印 mp4

无需签名算法、WebView 或 App API，四步 HTTP 链：

```
1. 短链解析   GET https://v.douyin.com/{code}/           → 302 Location 里的 /share/video/{数字id}/
2. 注册 ttwid POST https://ttwid.bytedance.com/ttwid/union/register/
              body: {"region":"cn","aid":1768,...,"service":"www.ixigua.com","union":true}
              收 Set-Cookie 里的 ttwid。接口可能单跳直接回，也可能走 redirect_url，
              实现需收全部跳转的 Set-Cookie。
3. 分享页 SSR GET https://www.iesdouyin.com/share/video/{数字id}/  (Cookie: ttwid=...)
              → window._ROUTER_DATA JSON → loaderData.video_(id)/page.videoInfoRes.item_list[0]
                ├ video.play_addr.uri      ← 关键（形如 v0d00fg10000...）
                ├ video.play_addr.url_list → aweme.snssdk.com/aweme/v1/playwm/...（带水印口）
                └ desc / author / cover / duration
4. 无水印直链 GET https://aweme.snssdk.com/aweme/v1/play/?video_id={uri}&line=0
              → 302 → douyinvod.com 原始流（无 logo 路径，体积约为带水印版 6.7 倍）
```

关键点：

| 项 | 说明 |
|---|---|
| play 接口参数 | 传数字 id 返回 200 空 text/plain（静默失败）；必须传 uri |
| ttwid | 分享页不带则报错页，_ROUTER_DATA 里无视频数据 |
| PC 站 | www.douyin.com 有 `_$jsvmprt` JS 虚拟机挑战，纯 HTTP 过不去 |
| m.douyin.com/share | 无 ttwid 同样报错页 |
| UA | playwm/play 有风控抖动；用安卓 Chrome 移动 UA，App UA 会被 404 |
| 直链有效期 | douyinvod URL 带过期时间，拿到即下载，不能囤 |

## 二、B站：官方 API → 单文件 mp4

无需登录或签名，三步：

```
1. 详情     GET https://api.bilibili.com/x/web-interface/view?bvid={BV}
            → code:0，拿 aid / cid / title / 分P列表
2. 播放地址 GET https://api.bilibili.com/x/player/playurl?avid={aid}&cid={cid}
            &fnval=1&platform=html5&high_quality=1&qn=80
            → code:0，durl[0].url=单文件 mp4 直链
            不传 qn 则默认回 16（360P）
            档位不能信 data.quality：无登录时可能虚标。
            真实分辨率用 Range 取 mp4 头 8KB，解析 moov 里的 tkhd；解析失败再退回档位名。
3. 下载     GET 该 url（普通浏览器 UA 即可；带不带 Referer 都回 200/206）
```

清晰度：

| 参数组合 | 结果 |
|---|---|
| fnval=1 + platform=html5 + high_quality=1（不传 qn） | 单文件 mp4，quality=16（360P），免合流 |
| 同上 + qn=80 | 单文件 mp4，免合流、无需登录；实际清晰度取决于源，API 的 quality 可能虚标，须读 mp4 头确认 |
| fnval=16 + platform=html5 + high_quality=1 | 仍回 durl 单文件 mp4；不传 qn 同样 360P |
| fnval=4048 | 回 DASH，需音视频合流，App 不用 |

默认 fnval=1 + qn=80：mp4 单文件，省掉 ffmpeg 合流、省体积。更高档（1080P60/4K/HDR）才需要登录 cookie（SESSDATA）。
