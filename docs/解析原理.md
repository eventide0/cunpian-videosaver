# 存片：解析原理（开源版）

## 一、抖音：短链 → 无水印 mp4（无签名 / 无 WebView / 无 App API）

四步 HTTP 链：

```
1. 短链解析   GET https://v.douyin.com/{code}/           → 302 Location 里的 /share/video/{数字id}/
2. 注册 ttwid POST https://ttwid.bytedance.com/ttwid/union/register/
              body: {"region":"cn","aid":1768,...,"service":"www.ixigua.com","union":true}
              收 Set-Cookie 里的 ttwid（2026-11-27 复测：200 单跳直接回；
              历史上出现过 redirect_url 流程，实现要两种都吃得下）
3. 分享页 SSR GET https://www.iesdouyin.com/share/video/{数字id}/  (Cookie: ttwid=...)
              → window._ROUTER_DATA JSON → loaderData.video_(id)/page.videoInfoRes.item_list[0]
                ├ video.play_addr.uri      ← 关键（形如 v0d00fg10000...）
                ├ video.play_addr.url_list → aweme.snssdk.com/aweme/v1/playwm/...（带水印口）
                └ desc / author / cover / duration
4. 无水印直链 GET https://aweme.snssdk.com/aweme/v1/play/?video_id={uri}&line=0
              → 302 → douyinvod.com 原始流（无 logo 路径，体积约为带水印版 6.7 倍）
```

坑位清单：

| 坑 | 事实 |
|---|---|
| play 接口传数字 id | 返回 200 空 text/plain（静默失败）；必须传 uri |
| 分享页不带 ttwid | 返回「抱歉出错了」错误页，_ROUTER_DATA 里无视频数据 |
| www.douyin.com（PC 站） | 有 `_$jsvmprt` JS 虚拟机挑战，纯 HTTP 过不去，不要走这条 |
| m.douyin.com/share | 无 ttwid 同样报错页 |
| playwm/play 时好时坏 | 有风控抖动（首轮 302 正常、随后 404/空），UA 用安卓 Chrome 移动 UA 可过；App UA（com.ss.android.ugc.aweme/...）会被 404 |
| ttwid 注册接口已改版 | 2026-11-27 复测：200 单跳直接 Set-Cookie，不再是 redirect_url 流程；代码需手动收全部跳的 Set-Cookie 才稳 |
| 直链有效期 | douyinvod URL 带过期时间，拿到即下载，不能囤 |

未验证：ttwid 有效期与注册频率限制；图集（note）类型的 uri 提取；高频下载是否要求 Referer（低频实测不要求）。

## 二、B站：官方 API → 单文件 mp4（无登录 / 无签名）

三步：

```
1. 详情     GET https://api.bilibili.com/x/web-interface/view?bvid={BV}
            → code:0，拿 aid / cid / title / 分P列表
2. 播放地址 GET https://api.bilibili.com/x/player/playurl?avid={aid}&cid={cid}
            &fnval=1&platform=html5&high_quality=1
            → code:0，data.quality=16（360P），durl[0].url=单文件 mp4 直链
            ⚠ 判档位只看 data.quality，别读 accept_description（那只是"可提供"清单）
3. 下载     GET 该 url（普通浏览器 UA 即可；实测带不带 Referer 都回 200/206）
```

清晰度事实：

| 参数组合 | 实测结果 |
|---|---|
| fnval=1 + platform=html5 + high_quality=1 | 单文件 mp4，quality=16（360P），免合流 |
| fnval=16 + platform=html5 + high_quality=1 | 同样回 durl 单文件 mp4（不是 DASH），quality 同为 16 |
| 无 SESSDATA | 样本封在 360P；是否所有视频都能到 480P/720P 未逐个验证 |
| 要 1080P+ | 需登录 cookie（SESSDATA）+ 可能 WBI 签名 |

默认 fnval=1：mp4 单文件，省掉 ffmpeg 合流、省体积。

未验证：WBI 签名（w_rid）在高频调用时是否触发；番剧/课程等特殊 cid 结构。
